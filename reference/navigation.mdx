Check the selected engagement before searching. Use the sidebar to open Home, Questions, Sources, Requests, Business model, Ask, Decisions & definitions, Opportunities, Solution designs, Engagement, Activity or Product tour.

## Command palette

Press **Cmd+K** on macOS or **Ctrl+K** on other platforms. Search for a record, or type **>** to find commands. Use arrow keys to choose a result, Enter to open it and Escape to close the palette.

Search is engagement-scoped. It helps navigate available records and source material; it is not an AI answer or a guarantee that every relevant passage has been reviewed.

## Keyboard navigation

Press **G**, then the key below when you are not typing in a field.

| Key | Destination |
| --- | --- |
| H | Home |
| Q | Questions |
| S | Sources |
| M | Business model |
| A | Ask |
| D | Decisions & definitions |
| O | Opportunities |
| L | Solution designs |
| E | Engagement |
| T | Activity |
| / | Search |

These shortcuts do not accept or apply changes. Requests remains available from the sidebar and command palette.

## Exact links and history

Record links can preserve an answer, question, source, assessment or model-version context. Use the application's links rather than editing identifiers by hand. If an exact record is unavailable, return to the current page and locate it with appropriate access; do not assume a different record is equivalent.

Browser Back returns through navigation history. Draft retention has [limits](/reference/limits-and-recovery): save before reload or sign-out.
