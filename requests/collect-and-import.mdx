## Prepare and open a collection

Draft the request, connect it to the relevant investigation, review the wording and reorder prompts as needed. Preview the collection before opening it. Opening freezes its prompts; closing stops new responses.

<Warning>
Collection links are authorized workspace links, not public respondent forms. Responding or joining requires appropriate signed-in editing access. Copying or opening a link does not send an invitation or message.
</Warning>

Distribute a link through your approved communication process only when the intended participant has suitable access. For people who do not use the workspace, use an External/manual request and add returned material through [Sources](/sources/add-and-review).

## Review and import

1. Open the response and inspect its content.
2. Check the respondent label and the authenticated recorder. A label is not proof that the named person signed in; keep unknown attribution explicit.
3. Import the response when it is ready to become source material.
4. Follow the imported-source link and check the resulting version and content.

Import is a deliberate step and should produce one source for that response. If a save acknowledgment is uncertain, reconcile the existing result before recreating it. Import does not analyze the material, apply model changes or resolve the investigation.

External/manual records do not represent automatically sent requests or verified reply counts. Record the actual collection work and preserve the returned material.

See [video conversations](/requests/video-conversations) for call-specific limits and [recovery](/reference/limits-and-recovery) for interrupted saves.
