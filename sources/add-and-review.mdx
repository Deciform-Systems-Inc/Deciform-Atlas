title: "Add and review sources"
description: "Preserve material, inspect extracted text and link the exact supporting passage."
---

Open **Sources** to upload a file or paste text. Give the source a useful title. After saving, inspect the text before using it as evidence.

## Supported material

| Format | Review consideration |
| --- | --- |
| TXT or Markdown | Check headings and paragraph boundaries. |
| Text-based PDF | Check page locations and extraction order; scanned PDFs are not supported. |
| DOCX | Check the extracted text against the original document. |
| CSV | Review logical rows, including quoted fields that span lines. |
| XLSX | Review the sheet and row; the importer does not calculate formulas. |

Files can be up to **8 MB**. Text is limited to **500,000 characters**; split larger material into meaningful sources. Complex files may also exceed parser limits. Download the preserved original when you need to compare extraction with the source file.

## Save an exact evidence passage

1. Open the source version you intend to cite.
2. Select or identify the exact passage. If the same words appear more than once, choose the correct occurrence and inspect its location.
3. Classify the account as policy, practice or proposal. Set branch and period where known; leave genuinely unknown context explicit.
4. Save the citation and reopen it to check its quote and source context.

A citation points to a specific source version. New material does not rewrite earlier evidence. Older sources without reliable format metadata may show raw-text locations instead of a page, sheet or row label.

## Search and analysis

Use source search to find text, titles or filenames. With AI enabled, source analysis can suggest investigations and findings. Inspect those suggestions in [Questions](/investigations/review-and-apply) before accepting changes.

<Note>
Assessment and citation counts describe saved review work. They do not prove that every relevant fact in a source has been found or assessed.
</Note>
